# Implementation Planning

1. Inspect the relevant application entry points, dependency manifest, platform configuration, and existing planning format.
2. Write actionable, ordered tasks with concrete verification criteria.
3. Reference only files that have been confirmed to exist; distinguish new files from existing files.
4. Include testing and release-readiness tasks.
5. Read the final plan after writing it before declaring it complete.
